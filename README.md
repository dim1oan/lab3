## 📌 Описание проекта
Десктопное приложение с графическим интерфейсом на базе библиотеки **Tkinter**, реализующее классическую игру «Крестики-нолики» для двух участников.

### 🚀 Основные возможности
- **Игровое поле 3x3:** интерактивные кнопки с цветовым разделением ходов (синий `X`, красный `O`).
- **Алгоритм победы и ничьей:** автоматическая проверка 8 победных комбинаций (3 горизонтали, 3 вертикали, 2 диагонали) и выделение победного ряда светло-зеленым цветом.
- **Динамическая адаптивность:** использование сеточного компоновщика `grid` с настройкой весов (`weight=1`) через `grid_rowconfigure` и `grid_columnconfigure`, благодаря чему кнопки и поле плавно масштабируются при растягивании окна.
- **Главное меню приложения (`tk.Menu`):**
  - **Игра:** «Новая игра» (`Ctrl+N`), «Тест обработки ошибки», «Выход» (`Alt+F4`).
  - **Справка:** «Правила игры», «Об авторе».
- **Отказоустойчивость:** изоляция критических зон блоками `try-except`, перехват системных исключений `tk.TclError` и отображение информативных модальных окон `messagebox.showerror` без аварийного закрытия приложения.
- **Безопасное завершение:** перехват системного протокола `WM_DELETE_WINDOW` с запросом подтверждения выхода.
